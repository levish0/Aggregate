# Cartographic lettering and construction interface — 2026-09-06

## Decisions and implementation

- Gameplay uses a persistent map with a left docked inspector, icon tabs, top-right clock/speed controls and right outliner. The visual theme remains monochrome translucent; Victoria screenshots define arrangement/density, not the ornamental UI skin. Construction view has a compact construction-industry summary and dense project rows. B opens national construction; state cards route construction to a real owned site.
- Country names are flat world-oriented cartographic quads, not screen-space text or terrain-deformed meshes. `country_labels/placement.rs` groups nearby land, searches owned-land rectangles for position/angle/size, and excludes distant holdings from the main label extent. `typography.rs` rasterizes bundled Pretendard using ab_glyph. `material.rs` and `assets/shaders/country_lettering.wgsl` composite transparent lettering after terrain with depth writes disabled and Always depth comparison. This fixes mountain clipping and unwanted rectangular artifacts. Tiny projected labels fade; camera rotation does not reorient or rescale label entities.
- Label preparation runs on the async compute pool once per map/language, persists across screen rebuilds, and logs preparation time/count. Current local data produced 199 fitted labels in roughly 1.6–2.1 seconds off the render thread. These are straight fitted labels; curved baselines, secondary island/overseas labels, complex-script shaping and dynamic conquest invalidation remain future work. Ownership input is the existing map catalog.
- Notifications are transient dismissible toasts with hover-paused expiry and no replay from retained history. The stack uses the outliner's shared width/right offset and appears to its LEFT, leaving the panel unobscured. Construction feedback uses short localized text. A future personalized economic/geopolitical news system is a distinct feature.
- Building cards and project progress retain their UI entities across simulation revisions. Pending UUID-backed construction requests immediately contribute to target levels, are reconciled on acknowledgement, and are individually removed on rejection. Worker commands are drained in bounded batches with one published snapshot/index per batch; the client drains responses in bounded batches. Expensive simulation validation still exists and asynchronous execution alone does not establish a throughput/FPS budget.
- New-game flow is main menu → country setup → map. Continue appears for an existing geographic session. Public-health toggle and terrain/political dropdown were removed from ordinary gameplay/setup. Program loadout controls belong in a future launcher/configuration flow.
- Map presentation blends political coloring with detailed terrain by zoom, caps the far view, preserves horizontal wrapping and top/bottom table framing, and highlights administrative states. Province IDs remain internal geographic/simulation units: the economy has NOT been migrated to state-only storage.

## Related simulation/asset changes in this workstream

- Construction industry is an actual facility definition producing non-storable national construction points from employed workers and timber/tools inputs. Supply is allocated only to domestic projects, idle/foreign-only demand consumes no sector inputs, and sector labor is not counted twice. Local manual construction remains a bootstrap path. Actual production inputs/outputs and workforce are exposed in building cards/tooltips.
- Construction work fields use `construction_points` / `remaining_construction_points`. Save schema **5**, ruleset **aggregate-program-runtime/2**, scenario schema **3** supersede the previous worker-performance entry. No migration for old saves is claimed.
- Terrain preparation imports all **46** declared diffuse/normal layers and the original material index/intensity placement maps into mipmapped DDS arrays/compiled masks. Packed normals use the source G/A convention. This remains short of full Victoria terrain rendering: vegetation, cities/roads, full water/shadow/PBR behavior are not complete.
- Programs remain compiled Rust providers behind the existing SDK with daily prepare/commit boundaries. Full fine-grained economy/military/trade/currency/company provider decomposition and a launcher are not complete. Wage/treasury/bond/FX accounting is not implemented. Default geographic population is still synthetic per-province initialization, NOT complete 2026 demographic data.
