`solid/*.svg` are the original 24 solid icons. `solid/*.png` are white, 96-pixel raster derivatives generated with resvg for native Bevy UI rendering; the client applies tint and display size. Both forms use ordinary Git storage, not LFS. The license applies to the SVG sources and their derivatives.
